
# MovieBook

Aplicação web para catalogar filmes e livros, pesquisar obras por
diferentes critérios e permitir que os usuários interajam com o catálogo.

## Tecnologias

### Frontend
- Next.js
- React
- TypeScript

### Backend
- Python
- Flask

### Banco de dados
- PostgreSQL
- SQLAlchemy
- Flask-Migrate

## Estrutura do projeto

- `frontend/`: aplicação web Next.js.
- `backend/`: API Flask.
- `README.md`: documentação do projeto.

## Funcionalidades previstas

- Cadastro, login e recuperação de senha.
- Catálogo compartilhado de filmes e livros.
- Pesquisa e filtros avançados.
- Navegação por gêneros.
- Favoritos, avaliações e comentários.
- Relacionamento entre livros e adaptações cinematográficas.
- Edição e exclusão de obras pelo usuário responsável.

## Desenvolvimento

As instruções de instalação e execução serão adicionadas
conforme a configuração do frontend, backend e banco de dados.
